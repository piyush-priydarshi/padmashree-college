# 🎓 Padmashree College Website

A modern, responsive, and full-stack institutional website developed for **Padmashree College, Nepal**. The platform provides an engaging online presence while enabling administrators to manage content through a dedicated dashboard.

---

## 🌐 Live Demo

>https://padmashree-college-tinkune-np.vercel.app/

---


## ✨ Features

### 🌍 Public Website

- Modern landing page
- Responsive design
- Academic programs
- Student life
- News & Announcements
- Events
- Gallery
- Contact page
- Admission page
- Newsletter subscription

### 🔐 Admin Dashboard

- Secure Admin Login
- Manage News
- Manage Events
- Manage Programs
- Manage Gallery
- Manage Testimonials
- View Contact Messages
- Manage Admission Applications
- Site Settings

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/piyush-priydarshi/padmashree-college.git
```

Install dependencies

```bash
npm install
```

Create an `.env` file

```env
DATABASE_URL=
NEXTAUTH_SECRET=
NEXTAUTH_URL=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
EMAIL_USER=
EMAIL_PASS=
```

Run development server

```bash
npm run dev
```
